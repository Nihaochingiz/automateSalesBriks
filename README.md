# automateSalesBriks

Скрипт для автоматического создания персонализированных документов из шаблона Google Docs на основе данных из Google Sheets.

## Как это работает

Скрипт читает данные из таблицы, подставляет их в шаблон документа и сохраняет готовые файлы в указанную папку. Повторные запуски не создают дубликаты — уже сгенерированные документы пропускаются.

## Структура таблицы (лист "Data")

| Колонка | Поле | Описание |
|---------|------|----------|
| A (0) | `{{number}}` | Номер документа |
| F (5) | `{{company}}` | Название компании |
| G (6) | `{{person}}` | ФИО контактного лица |
| H (7) | Document Link | Заполняется автоматически (ссылка на созданный документ) |

> **Важно:** Колонка H не должна заполняться вручную — скрипт сам запишет туда ссылку.

## Настройка

Перед использованием укажите в коде:

```javascript
// ID вашего шаблона документа
const googleDocTemplate = DriveApp.getFileById('ВАШ_ID_ШАБЛОНА');

// ID папки для готовых документов
const destinationFolder = DriveApp.getFolderById('ВАШ_ID_ПАПКИ');
```

### Как получить ID

Из ссылки на Google Docs/Drive:
```
https://docs.google.com/document/d/1NkYc7LsfDk4gL6x_1234567890/edit
                                         ↑_____________↑
                                              это ID
```

## Шаблон документа

В вашем Google Docs-шаблоне используйте плейсхолдеры:

```
Номер документа: {{number}}
Компания: {{company}}
Контактное лицо: {{person}}
```

Скрипт автоматически заменит их на данные из таблицы.

## Установка

1. Откройте Google Sheets с данными
2. Перейдите в `Расширения → Apps Script`
3. Скопируйте код в редактор
4. Сохраните проект (💾)
5. Обновите страницу таблицы

## Использование

1. Заполните данные в листе `Data`
2. В меню таблицы появится `AutoFill Docs`
3. Нажмите `Create New Docs`

Скрипт:
- Создаст документы для всех строк без ссылки в колонке H
- Подставит данные в шаблон
- Сохранит готовые документы в указанную папку
- Запишет ссылки обратно в таблицу

## Защита от дублирования

Скрипт проверяет колонку H (`row[7]`):
- Если ссылка есть → документ уже создан, пропускаем
- Если ссылки нет → создаём новый документ

Это позволяет безопасно запускать скрипт повторно после добавления новых строк.

## Требования
